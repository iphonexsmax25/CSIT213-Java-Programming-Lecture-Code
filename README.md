# Steps to configure Java FX in NetBeans

## 1. Install JavaFX SDK
*(Skip this step if already installed)*

1. [Download the JavaFX SDK from the official website](https://openjfx.io).
2. Extract the downloaded setup file or ZIP file to a folder you can easily access (e.g., `C:\JavaFX`).

## 2. Configure Java Platform in NetBeans

1. Open NetBeans.
2. In the **Projects** window, right-click your project and select **Properties**.
3. Go to **Build → Compile**.
4. Next to **Java Platform**, click **Manage**.
5. In the **Java Platform Manager**, click **Add Platform**.
6. Select the folder where you extracted the JavaFX SDK.
7. Click **Next**, then finish the setup.
